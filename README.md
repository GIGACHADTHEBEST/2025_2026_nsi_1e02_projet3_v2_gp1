Jeu de dames

Nous avons choisi de reproduire le jeu de dames.

L’objectif est de créer une IA sur ce jeu. Nous voulons instaurer un système de progression sur celui-ci. L’IA doit être capable de progresser suite aux parties qu’il joue.
Pour cela elle doit comprendre l’objectif du jeu :
L’objectif est de prendre les pions de l’adversaire. Nous avons pris comme point de départ à respecter les règles donc en lui interdisant de faire des siennes. Ensuite nous avons pensé à comment réaliser le système de progression (le projet en groosss 😔😔)
Lorsque l’IA perd la partie elle va donc essayer de jouer différemment à la suivante, et lorsqu’elle gagne elle va reproduire ce qui a marché dans la partie.

Nous avons voulu ajouter la possibilité à deux pièces de s’affronter également dans une partie endiablée de dames classiques.

Donc dans la représentation visuelle du projet, dans le menu principale, vous pouvez choisir entre jouer seul contre l’ordinateur, entre l’ordinateur jouant seul contre vous, faire…
